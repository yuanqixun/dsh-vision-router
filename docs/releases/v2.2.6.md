# 2.2.6

Private Superbpm release based on upstream `main` after `v2.2.5`.

- Cache the model catalog in browser storage so the provider/model picker can render immediately on repeat visits.
- Open the General settings card by default and refresh catalog/capability data after the first paint.
- Preserve the DSH 0.1.7 local ConfigEditor bridge after upstream synchronization, avoiding an incorrect remote-settings fallback on loopback pages.

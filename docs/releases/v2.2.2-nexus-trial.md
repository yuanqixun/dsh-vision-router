# v2.2.2 — private Nexus compatibility trial

This patch is for testing DSH `0.1.7-rc.1` in a private Nexus repository. It is not a public Host support-window expansion.

- Avoid calling the removed Host `settings.register()` method when the newer settings service is present. Keep the legacy registered-scope path for older Hosts.
- Remove the browser plugin's hard dependency on `settingsScope` and select the newer `configForms` service when available.
- Preserve the old `settingsScope` path and add Host and browser startup regression tests for both service generations.

The DSH `0.1.7-rc.1` settings service exposes only fields marked volatile in the plugin Config. Vision Router's existing Config has not yet been migrated to that model, so the custom settings page may report that its form is unavailable. This patch tests startup compatibility; settings editing remains a separate migration.

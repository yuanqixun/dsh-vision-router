# v2.2.6-hxfl.1

Private HXFL performance build based on upstream Vision Router 2.2.5 plus the
current `origin/main` compatibility updates.

## Settings model picker

- Persist the last successful model catalog in browser `localStorage`, so a
  reopened Vision Router page can render provider and model choices
  immediately.
- Open the General settings card by default.
- Defer model-catalog and capability refresh until after the first browser
  paint, while keeping cached choices visible during background refresh or a
  transient refresh failure.

The cache is refreshed after startup and remains an acceleration layer only;
the Host model catalog remains authoritative.

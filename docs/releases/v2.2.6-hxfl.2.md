# 2.2.6-hxfl.2

Private HXFL build based on upstream `main` after `v2.2.5`.

- Keeps the model catalog in browser storage so the provider/model picker can render immediately on repeat visits.
- Opens the General card by default and refreshes catalog/capability data after the first paint.
- Restores the DSH 0.1.7 local ConfigEditor bridge after merging upstream, avoiding an incorrect fallback to the unavailable remote-settings channel on loopback pages.
